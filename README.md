# GTM Build Tracker

A read-only view of Tyler's 30-day GTM Engineer build plan (Oct 12 – Nov 10, 2026):
calendar, today's agenda, tomorrow's tasks and overall progress.

`index.html` is the page; `plan.js` is the data, regenerated from the live tracker at the
end of each working day and pushed here. GitHub Pages serves it as is — there is no build.

## Run it yourself

Want to work through the same 30 days? The plan is available as a template you can copy and follow with your own LLM, with the lessons from this run written into each day: [Marketing Engineer Bootcamp](https://github.com/Twishnoff/Marketing-Engineer-Bootcamp).
